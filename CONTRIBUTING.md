# Contributing

Each repository's README explains how to build and test it; follow it where it differs from this page.

- Open an issue before a large change so we can agree on the approach.
- Write commits in English with Conventional Commits, such as `fix(scope): describe the change`.
- Keep pull requests small, and describe them with What?, Why?, and How?.
- Never commit secrets. Report security issues privately; see SECURITY.md.
